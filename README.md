# Word-Segmentation

Проект решает задачу восстановления пробелов в непробельном тексте — например, преобразование этопримертекста → это пример текста.
Используются методы машинного обучения для определения границ слов на основе контекста символов.
Репозиторий содержит код предобработки данных, обучения модели и оценки качества.
